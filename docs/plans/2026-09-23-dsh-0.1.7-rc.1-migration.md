## client 侧 slot 是否受 RC1-23/24/28/33 影响 —— 逐条比对 rc.1 契约

用 registry `0.1.7-rc.1` 包与本地 `0.1.5-rc.2` checkout 的 `lib/types` 逐条比对：

| 面 | rc.1 结论 |
|---|---|
| `conversation.composer.dock` | `{ kind: 'list'; scope: 'session' }`，**无 owner**——与 rc.2 完全一致 |
| `PropsRuntime<'conversation.composer.dock'>` | `OwnerOf & KeyPropsOf & SlotInjectFace & ScopeStandardProps<'session'>`；与 rc.2 的等价（rc.1 抽出 `ScopeStandardProps`，语义相同） |
| `SessionStandardProps` | 仍是空接口 + `ui-conversation` 合并 `useConversation`/`useInput`/`inputActions`；`ui-session` 合并 `sessionId`——与 rc.2 一致 |
| `ui-chat` 对 `SessionStandardProps` 的合并 | 仍只有 `useChat: UseChat` |
| `ChatSnapshot.legacy` | 仍存在（`readonly legacy: LegacyConversationSlice`），`legacy.nodes` 可用 |
| `useInput`/`inputActions` | 仍在 session 标准 props |
| RC1-24 的 `turnTail` list 化 / `hookContext` 重塑 | 只作用于 `conversation.chat.node` / `conversation.chat.turnTail`，本插件不注册，不受影响 |

**结论：不受 RC1-23/24/28/33 影响。**
